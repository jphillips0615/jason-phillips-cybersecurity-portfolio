# Jason Phillips Cybersecurity Portfolio

A premium black/red/white cybersecurity portfolio built with Next.js, React, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000
